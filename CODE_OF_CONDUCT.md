# Code of Conduct

## Our pledge

We want participation in the `ster` project to be a welcoming, respectful, and
harassment-free experience for everyone, regardless of background or identity.

## Our standard

This project adopts the **Contributor Covenant, version 2.1** as its code of
conduct. Please read the full text here:

- <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

In short: be respectful and constructive, assume good faith, welcome newcomers,
and accept feedback gracefully. Behaviour that the Covenant defines as
unacceptable is not tolerated in any project space (issues, pull requests,
discussions, and any other channel).

## Scope

This Code applies within all project spaces and when an individual is
representing the project in public spaces.

## Enforcement

Reports of unacceptable behaviour can be sent privately to the maintainer at
**gbelbe@gmail.com**. All reports will be reviewed and handled confidentially.
Maintainers may remove, edit, or reject contributions, comments, and
participants that violate this Code, following the enforcement guidelines in the
Contributor Covenant.
