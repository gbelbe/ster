# Security Policy

## Supported versions

`ster` is distributed on PyPI. Security fixes are applied to the latest released
version; please upgrade to the most recent release before reporting an issue.

| Version | Supported |
|---------|-----------|
| latest release | ✅ |
| older releases | ❌ |

## Reporting a vulnerability

**Please do not open a public issue for security problems.**

Report privately through one of:

- **GitHub** — [Report a vulnerability](https://github.com/gbelbe/ster/security/advisories/new)
  (Security → Advisories → *Report a vulnerability*), or
- **Email** — gbelbe@gmail.com

Include, where possible: affected version, a description of the issue, steps to
reproduce or a proof of concept, and the potential impact.

## What to expect

- **Acknowledgement** within a few days.
- An assessment and, if confirmed, a fix on a private branch followed by a
  patched release.
- Credit in the release notes if you wish (let us know how you'd like to be
  attributed).

Thank you for helping keep `ster` and its users safe.
